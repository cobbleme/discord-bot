# Discord AI Bot

一個基於 **Discord.py** 與 **OpenAI API** 的多功能 Discord Bot，支援 AI
對話、隨機色圖、R18 控制與模組化擴充。

------------------------------------------------------------------------

## ✨ 功能特點

-   🤖 **AI 對話**：透過 OpenAI API 與 Bot 互動（角色定義可自訂）。
-   🎭 **角色切換**：支援讀取與重載 `role.txt` 角色設定（管理員限定）。
-   🖼️ **隨機色圖 (`/setu`)**：
    -   `/setu` 或 `/setu 0`：隨機 **非 R18 色圖**。
    -   `/setu 1`：隨機 **R18 色圖**（需擁有 R18 身分組或為管理員）。
    -   僅顯示圖片與作者資訊。
-   🔒 **權限控制**：
    -   管理員 ID（`ADMIN_ID`）具備完整權限。
    -   R18 模式僅限 `R18_ROLE_IDS` 內的身分組。
-   ⚙️ **模組化設計**：方便未來擴展（如音樂播放、管理工具）。

## 🔧 安裝與使用

### 1️⃣ 安裝套件

``` bash
pip install -r requirements.txt
```

### 2️⃣ 設定 `config.py`

``` python
TOKEN = "你的 Discord Bot Token"
API_BASE_URL = "https://api.openai.com/v1/chat/completions"
API_KEY = "你的 OpenAI API Key"

ADMIN_ID = 123456789012345678
R18_ROLE_IDS = [987654321098765432]

ROLE_FILE = "role.txt"
```

### 3️⃣ 啟動 Bot

``` bash
python bot.py
```

## 🎮 指令說明

### 🤖 AI 對話

-   在文字頻道輸入訊息，Bot 會依據 `role.txt` 的角色設定回覆。

### 🎭 角色重載（管理員限定）

    /reload

-   重新載入 `role.txt`，無需重啟 Bot。

### 🖼️ 隨機色圖

    /setu
    /setu 0
    /setu 1

-   `0`（或不輸入）：隨機 **非 R18 色圖**。
-   `1`：隨機 **R18 色圖**（需 R18 權限）。

Bot 會回傳圖片與作者資訊。
